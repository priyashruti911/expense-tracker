# 💸 Expense Tracker

A basic full-stack Expense Tracking application built as a take-home assignment.  
This project demonstrates a real-world application structure using **NestJS** (TypeScript), **ReactJS**, and **GraphQL**.

---

## 📚 Stack Used

- **Backend**: NestJS, TypeORM, GraphQL, SQLite
- **Frontend**: ReactJS, Apollo Client
- **API Communication**: GraphQL over HTTP

---

## 🚀 Features

- Add new expenses (description, amount, date)
- List all expenses
- Uses GraphQL for client-server communication
- Real-world folder structure and clean code practices

---

## 🏁 Getting Started

### Prerequisites

- Node.js >= 18.x
- npm

---

### 🖥 Backend Setup

1. Navigate to the backend folder:
   ```bash
   cd backend
2. Install dependencies:
npm install
3. Start the server:
npm run start:dev
The GraphQL Playground will be available at: http://localhost:3001/graphql

🌐 Frontend Setup
1. Navigate to the frontend folder:
cd frontend
2. Install dependencies:
npm install
3. Start the React app:
npm start
App runs at: http://localhost:3000
